Role-Aware Workspaces

Tailored dashboards for Citizens, Lending Banks, Legal Authorities, and Administrators with isolated permissions and secure views.

Case Lifecycle Engine

Rigid 6-state transition lifecycle preventing illegal status jumps, terminal state re-opening, or unprivileged case manipulations.

Immutable Audit Logging

Every administrative action and role change is committed transactionally with full provenance tracking and target notification dispatch.

In-App Transparency

stateDiagram-v2
    [*] --> OPEN: Case Created (Citizen/Bank)
    OPEN --> UNDER_REVIEW: Authority Claims Queue
    UNDER_REVIEW --> AWAITING_RESPONSE: Clarification / Evidence Required
    AWAITING_RESPONSE --> UNDER_REVIEW: Citizen/Bank Updates Case
    UNDER_REVIEW --> ESCALATED: Legal / Regulatory Dispute Flagged
    ESCALATED --> UNDER_REVIEW: Resolution Proposed
    UNDER_REVIEW --> RESOLVED: Claim Verified / Lien Discharged
    UNDER_REVIEW --> CLOSED: Completed / Dismissed
    RESOLVED --> [*]
    CLOSED --> [*]

API Reference

tRPC v11 Procedure Catalog

QUERY cases.list

Returns all cases visible to the authenticated user's role scope.

All Roles
MUTATION cases.create

Creates a new property lien dispute case with unique reference ID.

Citizen / Bank
MUTATION cases.updateStatus

Advances or updates the lifecycle state of a case according to transition rules.

Authority / Admin
ADMIN MUTATION users.changeRole

Updates user role with atomic audit record and recipient notification.

Admin Only

Get Started

Running LienGuard in 3 Steps

1

Clone and Install Dependencies

git clone https://github.com/Rishisharma029/lien-guard.git && cd lien-guard && pnpm install
2

Configure Environment & Migrate Database

cp .env.example .env && pnpm run db:push
3

Launch Development Server

pnpm run dev
